# BOT SPOT

Десктоп-менеджер Telegram/Go/Python/Node/Docker-ботов на удалённом Linux-сервере: подключился по SSH — управляй ботами, файлами, деплоем и бэкапами из одного окна.

## Возможности

- **Боты** — автопоиск systemd-юнитов и docker-контейнеров, статус, PID, память/CPU, фильтры; кнопки Старт / Стоп / Рестарт / Обновить; live-логи journalctl с поиском, фильтром по уровню и сохранением; мониторинг сервера (CPU, RAM, диск, сеть, load) прямо в шапке.
- **Файлы** — двухпанельный SFTP-файл (как в Total Commander): перетаскивание, очереди загрузки/скачивания с прогрессом и отменой, разрешение конфликтов, создание папок, переименование, удаление, копирование.
- **Деплой** — сборка проекта локально, загрузка на сервер с прогрессом и отменой, защита важных файлов, проверка окружения, перезапуск юнита после доставки.
- **Бэкапы** — задания бэкапа баз/папок с сервера на локальную машину, история последних бэкапов, отмена, общий или свой корень для каждого задания.
- **Терминал** — ПКМ по боту → «Открыть терминал»: Windows Terminal с `ssh` в папке проекта. При первом открытии приложение ставит на сервер собственный ed25519-ключ, дальше вход без пароля.
- **Профили** — несколько серверов; пароль хранится в системном хранилище (Windows Credential Manager) и подставляется при переподключении.

## Запуск

Скачай `bot-spot.exe` из [Latest release](../../releases/latest) — установка не нужна, зависимости (PySide6, paramiko, keyring) уже внутри.

Требования: Windows 10/11; для вкладки «Терминал» — встроенный клиент OpenSSH и/или Windows Terminal (ставятся как компонент «Электронная оболочка OpenSSH» в Параметрах Windows).

## Сборка из исходников

```bash
pip install -r requirements.txt
python botmanager.py                 # запуск
python -m PyInstaller --noconfirm bot-spot.spec   # сборка exe -> dist/bot-spot.exe
```

## Структура

| Файл | Что делает |
|---|---|
| `botmanager.py` | главное окно: SSH, список ботов, логи, мониторинг, терминал |
| `files_tab.py` | SFTP-файл, очереди передач, стили сегментов |
| `deploy_tab.py` | деплой проектов на сервер |
| `backup_tab.py`, `backup_core.py` | задания и движок бэкапов |
| `env_editor.py` | редактор `.env` бота |
| `bot-spot.spec` | конфигурация PyInstaller |
